How it works

Each column = one 4-hole tablet.
Each row = one pick (weft shot).
Use at most 2 colors per column for standard tablet weaving.

Holes A, B hold Color 1; holes C, D hold Color 2.
Turning F (forward) or B (backward) selects which face shows.
